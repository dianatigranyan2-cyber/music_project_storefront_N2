# Melo storefront

Отдельная адаптивная витрина Melo на HTML, CSS и JavaScript.

Переключатель в правом верхнем углу меняет текст страницы на русский, армянский или английский; выбранный язык сохраняется в браузере. Папку `music_project_storefront` можно развернуть отдельно как статический сайт. Для проверки чата локально запустите витрину на `http://localhost:4173` и Melo на `http://localhost:3000`; открытие `index.html` как `file://` покажет страницу, но чат работать не будет.

Раздел тарифов — предварительный макет: окончательные цены, лимиты и состав планов ещё не утверждены.

## Чат поддержки

Виджет доступен посетителям без аккаунта. Сообщения отображаются в Melo в отдельном разделе «Обращения с витрины» для аккаунтов, которым разрешён `is_music_admin()`. Администратор может ответить посетителю; ответ появится в виджете в том же браузере. Это чат, не email.

Чтобы включить его в развёрнутой версии:

1. Примените `../supabase/support_inbox.sql` в Supabase SQL Editor.
2. В настройках Vercel проекта Melo задайте `MELO_STOREFRONT_ORIGIN` как точный HTTPS origin опубликованной витрины (без пути; несколько origin можно разделить запятыми), затем redeploy Melo.
3. Проверьте адрес Melo в `support.js`: локальная витрина обращается к `http://localhost:3000/api/support/public`, опубликованная — к `https://music-project-blue-mu.vercel.app/api/support/public`.
4. Разверните `music_project_storefront` как отдельный статический сайт. Для локального просмотра API разрешает `http://localhost:4173` в dev-режиме Melo.

Ключ переписки хранится в localStorage браузера посетителя; продолжить её можно в этом же браузере. В таблицах доступ напрямую закрыт, публичные функции позволяют гостю читать только переписку по его случайному секретному ключу, а список обращений и ответы доступны только администраторам Melo.
